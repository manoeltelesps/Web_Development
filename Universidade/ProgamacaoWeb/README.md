# 💻 Programação Web

Aulas e atividades práticas da disciplina de Programação Web, com foco em JavaScript no navegador: manipulação do DOM, eventos e lógica de programação.

## 📂 Estrutura
| Pasta | Descrição |
|---|---|
| `Aulas/06-03/` | Aula introdutória de JavaScript (script externo, `console.log`/`alert`) |
| `Aulas/20-03/` | Aula sobre eventos: cliques, hover, `addEventListener` e drag and drop |
| `Atividades/Atividade2_ExerciciosJavaScript/` | Exercícios de lógica em JavaScript: adivinhar o número, pedra-papel-tesoura, tabuada, triângulo de asteriscos e soma de série |
| `Atividades/Atividade3_DOOM/` | Atividade de manipulação do DOM: contador de cliques, texto dinâmico, contador de caracteres e lista de itens |

Cada pasta de atividade inclui o enunciado em PDF junto com o código.
