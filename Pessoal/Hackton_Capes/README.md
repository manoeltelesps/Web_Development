# 🎓 Sistema Colaborativo de Pesquisadores

Protótipo desenvolvido durante o **Hackathon Portal Periódico CAPES**, explorando a ideia de uma plataforma colaborativa para equipes de pesquisadores centralizarem documentos, tarefas e a comunicação entre projetos. A interface visual reaproveita o layout do Portal de Periódicos CAPES como base para apresentar o conceito, priorizando agilidade na apresentação das ideias em vez de funcionalidades completas.

## 📂 Arquivos
| Arquivo/Pasta | Descrição |
|---|---|
| `index.html` | Página inicial do protótipo, com layout inspirado no Portal de Periódicos CAPES |
| `templates/periodicos_v3/` | Estilos (CSS) reaproveitados do template do portal |
| `imagens/` | Capturas de tela e ícones usados na interface |
